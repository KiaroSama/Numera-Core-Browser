The loader takes trusted root bytes from its caller and uses a persistent datastore to compare metadata versions across refreshes. An isolated local fixture with freshly signed metadata retrieved the expected target, rejected a same-size target alteration with its digest check, and rejected an older signed timestamp against retained state. The current datastore overwrites individual metadata files, so Numera must protect those files as a durable generation under a cross-process update lock. The updater must carry forward a verified rotated root and recover safely from interrupted writes. Test that boundary, target staging and leased-package rollback before enabling updates.
