# Numera Core Browser

An independent browser runtime for [Numera Browser](https://github.com/KiaroSama/Numera-Browser), following the GoLogin/Orbita product boundary: the manager owns profiles; Core owns the browser runtime. The initial delivery targets an owned Chromium source build and retained browser chrome, with a shared Rust control plane.

**Development status: Gate A in progress. No owned browser engine, browser GUI, or integration-ready release is available yet.** A passing Rust check never implies a passing browser-source build. See [scope](docs/scope.md), [original handoff](docs/original-build-specification.md), and the separate source-build feasibility workflow.
